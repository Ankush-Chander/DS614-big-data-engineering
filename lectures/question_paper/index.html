Big Data Engineering - 50 Marks Question Paper

Section A: Multiple Choice Questions (20 marks, 1 mark each)

Instructions: Choose the correct answer for each question.

  1. What is the primary characteristic of a B-tree that makes it suitable for disk-based storage? a) It's a binary tree b) It has high fan-out and fat nodes c) It's optimized for memory access d) It uses only one key per node

  2. Which of the following is NOT a component of HDFS architecture? a) NameNode b) DataNode c) ResourceManager d) MasterNode

  3. In MapReduce, what happens during the shuffle and sort phase? a) Data is written to disk b) Keys are partitioned and copied to reducers c) Combiners are applied d) Mapper outputs are sorted locally

  4. What is the main advantage of columnar storage over row storage for analytical queries? a) Better compression b) Faster writes c) Reduced I/O bandwidth usage d) Better indexing

  5. In a B-tree with degree 1000, how many disk seeks would be required to find a key in a dataset of 10 billion items? a) 4 b) 3 c) 1000 d) 100

  6. What is the key difference between Size-Tiered Compaction and Leveled Compaction in LSM trees? a) Size-Tiered is write-optimized, Leveled is read-optimized b) Size-Tiered is read-optimized, Leveled is write-optimized c) Size-Tiered uses bloom filters, Leveled doesn't d) They're the same approach

  7. What is the primary purpose of a Bloom filter in LSM trees? a) To store data values b) To quickly determine if a key may be present in a segment c) To provide encryption d) To track memory usage

  8. In the MySQL InnoDB storage engine, what does a secondary index store as its 'value' in the leaf nodes? a) Only the column(s) specified in the WHERE clause. b) A direct pointer to the physical disk offset of the row. c) The entire row of data for faster retrieval. d) The primary key of the associated row.

  9. What is the main performance bottleneck in MapReduce? a) Disk I/O b) Network transfer during shuffle phase c) CPU processing d) Memory allocation

  10. What is the key concept behind data locality in MapReduce? a) Moving data to the computation b) Moving computation to the data c) Using multiple cores d) Parallel processing

  11. What is the primary benefit of using a log-structured storage engine? a) Faster reads b) Sequential writes are faster c) Better indexing d) Reduced memory usage

  12. Which of these is NOT a characteristic of a good hash function for distributed systems? a) Uniform distribution b) Deterministic c) Collisions should be minimized d) Random distribution

  13. What is the main difference between OLTP and OLAP systems? a) OLTP is for real-time processing, OLAP is for analytical processing b) OLTP is for batch processing, OLAP is for real-time processing c) OLTP is for data warehousing, OLAP is for transaction processing d) They're the same thing

  14. How does the size of the primary key affect the performance of a B+tree index? a) Key size has no impact as long as the total data fits on the disk. b) Smaller keys allow more entries per node, leading to a shallower tree. c) Larger keys are processed faster by modern 64-bit CPUs. d) Smaller keys increase the likelihood of hashing collisions.

  15. What does the "X" represent in the formula partition = hash(k_2) mod X in MapReduce? a) Number of reducers b) Number of mappers c) Number of blocks d) Number of nodes

  16. What is the primary purpose of a Combiner in MapReduce? a) To perform final aggregation b) To reduce network traffic by pre-aggregating intermediate results c) To encrypt data d) To compress output files

  17. What is the main benefit of using a columnar storage format? a) Better compression b) Faster random access c) Reduced I/O for analytical queries d) Better indexing

  18. What is the role of the ResourceManager in YARN? a) Stores data blocks b) Manages cluster resources and scheduling c) Handles data locality d) Provides fault tolerance

  19. What is the main characteristic of a narrow transformation in Spark? a) It requires shuffling b) It doesn't require data movement between nodes c) It's a data source operation d) It's a transformation that combines data from multiple partitions

  20. What is the main purpose of the NameNode in HDFS? a) Stores data blocks b) Manages the filesystem namespace and metadata c) Provides data locality d) Handles client requests

Instructions: Write "True" or "False" for each statement.

  1. HDFS blocks are replicated by default 3 times for fault tolerance. ______

  2. MapReduce is primarily used for real-time processing. ______

  3. In Spark, narrow transformations are faster than wide transformations because they don't require shuffling. ______

  4. The main performance bottleneck in MapReduce is usually the network transfer during the shuffle phase. ______

  5. The primary benefit of using a log-structured storage engine is that it provides better read performance than traditional storage. ______

  6. In a B-tree, each node can have at most the degree number of children. ______
