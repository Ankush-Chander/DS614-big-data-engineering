Big Data Engineering - Solution Paper

Section A: Multiple Choice Questions (20 marks, 1 mark each)

  1. What is the primary characteristic of a B-tree that makes it suitable for disk-based storage? Answer: b) It has high fan-out and fat nodes

  2. Which of the following is NOT a component of HDFS architecture? Answer: d) MasterNode

  3. In MapReduce, what happens during the shuffle and sort phase? Answer: b) Keys are partitioned and copied to reducers

  4. What is the main advantage of columnar storage over row storage for analytical queries? Answer: c) Reduced I/O bandwidth usage

  5. In a B-tree with degree 1000, how many disk seeks would be required to find a key in a dataset of 10 billion items? Answer: b) 3

  6. What is the key difference between Size-Tiered Compaction and Leveled Compaction in LSM trees? Answer: a) Size-Tiered is write-optimized, Leveled is read-optimized

  7. What is the primary purpose of a Bloom filter in LSM trees? Answer: b) To quickly determine if a key may be present in a segment

  8. In the MySQL InnoDB storage engine, what does a secondary index store as its 'value' in the leaf nodes? Answer: d) The primary key of the associated row

  9. What is the main performance bottleneck in MapReduce? Answer: b) Network transfer during shuffle phase

  10. What is the key concept behind data locality in MapReduce? Answer: b) Moving computation to the data

  11. What is the primary benefit of using a log-structured storage engine? Answer: b) Sequential writes are faster

  12. Which of these is NOT a characteristic of a good hash function for distributed systems? Answer: d) Random distribution

  13. What is the main difference between OLTP and OLAP systems? Answer: a) OLTP is for real-time processing, OLAP is for analytical processing

  14. How does the size of the primary key affect the performance of a B+tree index? Answer: b) Smaller keys allow more entries per node, leading to a shallower tree

  15. What does the "X" represent in the formula partition = hash(k_2) mod X in MapReduce? Answer: a) Number of reducers

  16. What is the primary purpose of a Combiner in MapReduce? Answer: b) To reduce network traffic by pre-aggregating intermediate results

  17. What is the main benefit of using a columnar storage format? Answer: c) Reduced I/O for analytical queries

  18. What is the role of the ResourceManager in YARN? Answer: b) Manages cluster resources and scheduling

  19. What is the main characteristic of a narrow transformation in Spark? Answer: b) It doesn't require data movement between nodes

  20. What is the main purpose of the NameNode in HDFS? Answer: b) Manages the filesystem namespace and metadata

Section B: True/False Questions (6 marks, 1 mark each)

  1. HDFS blocks are replicated by default 3 times for fault tolerance. Answer: True

  2. MapReduce is primarily used for real-time processing. Answer: False

  3. In Spark, narrow transformations are faster than wide transformations because they don't require shuffling. Answer: True

  4. The main performance bottleneck in MapReduce is usually the network transfer during the shuffle phase. Answer: True

  5. The primary benefit of using a log-structured storage engine is that it provides better read performance than traditional storage. Answer: False

  6. In a B-tree, each node can have at most the degree number of children. Answer: True

Section C: Short Answer Questions (24 marks, 2 marks each)

  1. What is the key difference between a hash index and a B-tree index? Answer: A hash index provides O(1) lookup time but doesn't support range queries, while a B-tree index supports both point and range queries with O(log n) time complexity.

  2. Define data locality in the context of distributed systems. Answer: Data locality refers to the principle of processing data where it resides, minimizing network transfer by scheduling computation on nodes that contain the data to be processed.

  3. Explain the role of the NameNode in HDFS architecture. Answer: The NameNode manages the filesystem namespace, stores metadata about files and directories, tracks which DataNodes store which blocks, and maintains the mapping of file blocks to DataNodes.

  4. What is lazy evaluation in Spark and why is it beneficial? Answer: Lazy evaluation means Spark delays execution until a result is actually needed. It's beneficial because it allows Spark to optimize the entire computation pipeline into a single efficient execution plan rather than executing operations one by one.

  5. Describe the process of compaction in LSM trees. Answer: Compaction is the process where multiple smaller sorted segments are merged into larger sorted segments. This process removes duplicate keys, handles deletions (tombstones), and reduces the number of segments that need to be searched during reads.

  6. What are the main challenges in implementing fault tolerance in distributed systems? Answer: The main challenges include detecting failures, recovering from failures without data loss, maintaining consistency across nodes, and ensuring availability while dealing with network partitions and node failures.

  7. What is the main advantage of columnar storage over row storage for analytical queries? Answer: Columnar storage allows for better compression and faster query performance for analytical workloads since queries typically access only a subset of columns, reducing I/O bandwidth usage.

  8. Explain the difference between Map and Reduce phases in MapReduce. Answer: The Map phase processes input data and generates intermediate key-value pairs, while the Reduce phase receives the intermediate key-value pairs from multiple mappers, groups them by key, and produces the final output.

  9. What is the purpose of a partitioner in MapReduce? Answer: The partitioner determines which reducer a particular intermediate key-value pair should be sent to, ensuring that related data is processed by the same reducer.

  10. Why are B-tree nodes often sized to match the size of a disk block (e.g., 16k)? Answer: B-tree nodes are sized to match disk block size to minimize disk I/O operations. When a node is read from disk, it reads an entire block, so matching the node size to the block size maximizes I/O efficiency.

  11. What is the primary performance drawback of using a completely random 128-bit UUIDv4 as a primary key in a B+tree? Answer: The primary drawback is that random UUIDs cause poor write performance due to index fragmentation, as new records are inserted at random locations in the index, leading to many page splits and poor cache locality.

  12. List down any 2 applications of Bloom filter in storage systems? Answer: 1) To quickly check if a key may exist in a segment before doing expensive disk lookups, 2) To track which keys have been deleted (tombstones) in LSM trees to avoid unnecessary disk reads.
