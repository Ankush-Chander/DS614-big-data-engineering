50-Marks Question Paper Plan for Big Data Engineering

Overview

This document outlines the structure and content for creating a 50-mark question paper for Big Data Engineering lectures. The exam will consist of: - 20 MCQs (single option correct) - 20 marks (1 mark each) - 6 True/False questions - 6 marks (1 mark each) - 12 2-mark questions - 24 marks (2 marks each) - Total: 50 marks

Difficulty Distribution

  • 50% Easy (10 MCQs, 3 True/False, 6 2-mark questions)
  • 25% Medium (5 MCQs, 2 True/False, 3 2-mark questions)
  • 25% Hard (5 MCQs, 1 True/False, 3 2-mark questions)

Topics Covered in Lectures

  1. Storage engines (Log-based, Hash indexes, SSTables, LSM trees)
  2. B-trees and database indexes
  3. Columnar storage vs Row storage
  4. Batch processing vs Online processing vs Stream processing
  5. HDFS architecture and concepts
  6. MapReduce framework concepts and execution pipeline
  7. Spark architecture and concepts
  8. Prerequisites for MapReduce (functional programming, Unix streams, hashing, etc.)

Question Paper Structure

Section A: Multiple Choice Questions (20 marks)

  • 10 Easy MCQs
  • 5 Medium MCQs
  • 5 Hard MCQs

Section B: True/False Questions (6 marks)

  • 3 Easy True/False
  • 2 Medium True/False
  • 1 Hard True/False

Section C: Short Answer Questions (24 marks)

  • 6 Easy 2-mark questions
  • 3 Medium 2-mark questions
  • 3 Hard 2-mark questions

Sample Questions

MCQ Sample Questions

Easy MCQs: 1. What is the primary characteristic of a B-tree that makes it suitable for disk-based storage? a) It's a binary tree b) It has high fan-out and fat nodes c) It's optimized for memory access d) It uses only one key per node

  1. Which of the following is NOT a component of HDFS architecture? a) NameNode b) DataNode c) ResourceManager d) MasterNode

Medium MCQs: 3. In MapReduce, what happens during the shuffle and sort phase? a) Data is written to disk b) Keys are partitioned and copied to reducers c) Combiners are applied d) Mapper outputs are sorted locally

  1. What is the main advantage of columnar storage over row storage for analytical queries? a) Better compression b) Faster writes c) Reduced I/O bandwidth usage d) Better indexing

Hard MCQs: 5. In a B-tree with degree 1000, how many disk seeks would be required to find a key in a dataset of 1 billion items? a) 30 b) 3 c) 1000 d) 100

  1. What is the key difference between Size-Tiered Compaction and Leveled Compaction in LSM trees? a) Size-Tiered is write-optimized, Leveled is read-optimized b) Size-Tiered is read-optimized, Leveled is write-optimized c) Size-Tiered uses bloom filters, Leveled doesn't d) They're the same approach

True/False Sample Questions

Easy: 1. HDFS blocks are replicated by default 3 times for fault tolerance. (True) 2. MapReduce is primarily used for real-time processing. (False)

Medium: 3. In Spark, narrow transformations are faster than wide transformations because they don't require shuffling. (True)

Hard: 4. The main performance bottleneck in MapReduce is usually the network transfer during the shuffle phase. (True)

2-Mark Short Answer Sample Questions

Easy: 1. What is the key difference between a hash index and a B-tree index? 2. Define data locality in the context of distributed systems.

Medium: 3. Explain the role of the NameNode in HDFS architecture. 4. What is lazy evaluation in Spark and why is it beneficial?

Hard: 5. Describe the process of compaction in LSM trees. 6. What are the main challenges in implementing fault tolerance in distributed systems?

Implementation Plan

Phase 1: Content Analysis and Planning (Completed)

  • Review all lecture materials to identify key concepts and their difficulty levels
  • Identify topics covered in lectures
  • Define difficulty level definitions
  • Create initial question paper structure
  • Develop sample questions for each category

Phase 2: Question Development

  • Create 10 easy MCQs
  • Create 5 medium MCQs
  • Create 5 hard MCQs
  • Create 3 easy True/False questions
  • Create 2 medium True/False questions
  • Create 1 hard True/False question
  • Create 6 easy 2-mark questions
  • Create 3 medium 2-mark questions
  • Create 3 hard 2-mark questions

Phase 3: Question Review and Validation

  • Review all questions for accuracy and clarity
  • Verify difficulty levels are correctly assigned
  • Ensure questions align with lecture content
  • Check for any ambiguity or confusion in question wording
  • Validate that all answer options are plausible but only one is correct

Phase 4: Final Compilation and Formatting

  • Assemble complete question paper with proper formatting
  • Ensure consistent formatting throughout
  • Verify all questions are properly numbered
  • Check that total marks equal 50
  • Add instructions and formatting as needed

Phase 5: Quality Assurance

  • Final proofreading of entire question paper
  • Verify all answer options are clearly labeled
  • Confirm question paper meets specified requirements
  • Ensure no content is missing or duplicated
  • Validate that all sections are properly structured

Difficulty Level Definitions

Easy

  • Basic facts and definitions
  • Simple recall of concepts
  • Direct application of knowledge
  • No complex reasoning required

Medium

  • Slightly more complex application
  • Requires understanding of relationships between concepts
  • Some analytical thinking needed
  • Moderate complexity in problem solving

Hard

  • Complex reasoning required
  • Integration of multiple concepts
  • Requires deep understanding
  • Attention to details or edge cases
