MapReduce Hands-on Lab Plan

Goal: Students will set up a Hadoop environment, understand HDFS basic commands, and run MapReduce jobs using both standard JARs and Python (Hadoop Streaming).

Lab 1: Environment Setup (Single Node Cluster)

Objective: Get a working Hadoop environment. 1. Prerequisites: Java 8+, SSH setup (passwordless localhost login). 2. Download & Install: - Download Apache Hadoop binary. - Configure JAVA_HOME in hadoop-env.sh. 3. Configuration: - core-site.xml: Set fs.defaultFS to hdfs://localhost:9000. - hdfs-site.xml: Set replication to 1 (since single node). 4. Initialization: - Format NameNode: hdfs namenode -format - Start DFS daemons: start-dfs.sh - Start YARN daemons: start-yarn.sh 5. Verification: Access web interfaces. - NameNode UI: http://localhost:9870 - ResourceManager UI: http://localhost:8088

Lab 2: HDFS Interaction

Objective: Basic manipulation of the distributed filesystem. 1. Copy From Local: - hdfs dfs -mkdir /input - hdfs dfs -put local_file.txt /input/ 2. List & Inspect: - hdfs dfs -ls / - hdfs dfs -cat /input/local_file.txt - hdfs dfs -tail /input/local_file.txt 3. Copy To Local: - hdfs dfs -get /input/local_file.txt ./downloaded_file.txt 4. Management: - Check disk usage: hdfs dfs -du -h / - Remove files: hdfs dfs -rm /input/local_file.txt

Lab 3: Running Classic MapReduce (WordCount)

Objective: Run the "Hello World" of MapReduce using provided Java examples. 1. Prepare Data: Upload a large text file (e.g., Book from Project Gutenberg) to HDFS /input/book.txt. 2. Run Job: 

hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-*.jar wordcount /input /output
3. Inspect Output: - Note: Output is a directory, not a file. - hdfs dfs -ls /output (Check for _SUCCESS and part-r-00000). - hdfs dfs -cat /output/part-r-00000 | head

Lab 4: Hadoop Streaming with Python

Objective: Write MapReduce logic in a familiar language (Python) using stdin/stdout. 1. Develop mapper.py: - Read lines from stdin. - Split into words. - Print word\t1 to stdout. 2. Develop reducer.py: - Read word\tcount from stdin. - Aggregate counts for same key (relying on input being sorted by key). - Print final word\tsum to stdout. 3. Test Locally (Crucial Step): - cat test_data.txt | ./mapper.py | sort | ./reducer.py 4. Run on Hadoop: 

mapred streaming \
  -input /input/book.txt \
  -output /output-python \
  -mapper mapper.py \
  -reducer reducer.py \
  -file mapper.py \
  -file reducer.py
